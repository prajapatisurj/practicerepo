
Components are the building blocks of a React application. In **React**, there are two types of components:
1. **Functional Components**
2. **Class Components** (Not discussed here, but still valid in React

**1️⃣ Functional Components**

A **Functional Component** is simply a **JavaScript function** that returns JSX. It is a simpler, cleaner, and more modern way to write components compared to class components.

```jsx
// Simple Functional Component
function Greeting() {
  return <h1>Hello, World!</h1>;
}
```
- `Greeting` is a **function** (Functional Component).
- The function **returns JSX** (`<h1>Hello, World!</h1>`).
- The name of the function **should start with an uppercase letter** (React expects that).

Using Functional Component
```jsx
function App() {
  return (
    <div>
      <Greeting />  {/* Using Greeting Component */}
    </div>
  );
}
```
In this example, `<Greeting />` is **rendering the `Greeting` component** inside the `App` component.

**2️⃣ Passing Data to Functional Components (Props)**

In React, you can **pass data** to components using **props** (short for "properties"). Props allow components to be **dynamic** and **reusable**.
```jsx
// Greeting component receiving props
function Greeting({ name }) {
  return <h1>Hello, {name}!</h1>;  // Displays the name passed as a prop
}

function App() {
  return (
    <div>
      <Greeting name="Alice" />  {/* Passing the 'name' prop to Greeting */}
      <Greeting name="Bob" />    {/* Passing the 'name' prop to Greeting */}
    </div>
  );
}



// Example 2: Greeting component receiving multiple props
function Greeting({ name, age }) {
  return <h1>{name} is {age} years old.</h1>;
}

function App() {
  return (
    <div>
      <Greeting name="Alice" age={25} />
      <Greeting name="Bob" age={30} />
    </div>
  );
}

```
###  **What is Hydration in React.js / Next.js?**
1. Hydration is the process where React takes over the static HTML generated by the server 
and makes it interactive in the browser by attaching event listeners and React’s virtual DOM.


### **Final Summary**

1. **Functional Components** are just JavaScript functions that return JSX.
2. You can pass **props** to make components **dynamic** and **reusable**.
3. You can manage **state** using the `useState` hook.
4. **Event handling** (e.g., `onClick`) can be done in functional components like normal JavaScript functions.
5. Functional components are **cleaner, simpler**, and **more modern** compared to class components.
