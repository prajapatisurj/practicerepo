- **ES6** stands for **ECMAScript 6**
-  JavaScript was originally created by **Brendan Eich** at **Netscape** in 1995.
-  To standardize the language, Netscape submitted it to **ECMA International**, a standards  organization.
-  ECMA created the **ECMAScript standard (ES)** in **1997**, defining the core rules for JavaScript.

**VERSION HISTORY**

- **ES1 (1997)** – The first official standard.
- **ES2 (1998)** – Small updates.
- **ES3 (1999)** – Added `try...catch` for error handling.
- **ES4** – **Skipped** due to major disagreements.
- **ES5 (2009)** – Added `strict mode`, `JSON.parse()`, `forEach()`, etc.
- **ES6 (2015)** – Major update (hence it's also called **ES2015**).
- **ES7, ES8, ES9, etc.** – Smaller yearly updates.


**Why is ES6 important?**

- It introduced **modern JavaScript** with features like `let`, `const`, arrow functions, and classes.
- It's the biggest update since ES5.
- Many React and modern web development features **depend on ES6+**.

After ES6, ECMAScript started getting **yearly updates** instead of waiting many years for a big update. That’s why we now have **ES7 (ES2016), ES8 (ES2017), ES9 (ES2018), etc.** instead of ES7 being another big jump.
